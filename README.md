# 💬 AI Sentiment Analyzer

An AI-powered web application that analyzes the sentiment of user-provided text and predicts whether the sentiment is **Positive** or **Negative**.

## 🚀 Features

* Analyze sentiment from text input
* Predicts Positive or Negative sentiment
* Machine Learning model for sentiment classification
* Text preprocessing and feature extraction
* Pre-trained model and vectorizer included
* Simple and interactive web interface
* Flask-based backend

## 🛠️ Technologies Used

* Python
* Flask
* Scikit-learn
* NLP
* HTML
* CSS
* JavaScript
* Pandas

## 🤖 Machine Learning

The project uses Natural Language Processing (NLP) techniques to process text and a trained Machine Learning classification model to predict sentiment.

The trained model and vectorizer are stored in the `models/` folder.

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/simran-commits/AI-sentiment-analyzer.git
```

### 2. Open the project folder

```bash
cd AI-sentiment-analyzer
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python3 app.py
```

Open the local URL shown in the terminal.
